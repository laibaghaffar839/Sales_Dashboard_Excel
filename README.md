# Retail Sales Dashboard using Microsoft Excel

## Project Overview
This project is an interactive retail sales dashboard built using Microsoft Excel. The dashboard helps analyze sales, profit, quantity, and customer trends using pivot tables, charts, slicers, and formulas.

## Key Insights
- Technology products generated higher profits
- Some categories had high sales but low margins
- Monthly and yearly trends were analyzed
- Interactive filters improved user analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- GETPIVOTDATA
- Excel Formulas

## Dashboard Features
- Sales Analysis
- Profit Analysis
- Quantity Analysis
- Top Products
- Interactive Filtering
